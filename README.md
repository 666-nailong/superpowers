# 电路分析学习助手 — 微信小程序

帮助大学本科电子信息/电气专业学生在线学习《电路分析》的微信原生小程序。

## 项目概述

| 项目 | 说明 |
|------|------|
| 技术栈 | 微信原生小程序（WXML + WXSS + JavaScript） |
| 数据存储 | wx.setStorageSync / wx.getStorageSync（本地存储） |
| 目标用户 | 信息工程、电子信息、电气等专业本科生 |
| 设计风格 | 极简实用、大量留白、线条简洁 |
| 主色调 | 深蓝色 `#1A365D`（专业/科技感） |
| 兼容性 | 微信 8.0+ |
